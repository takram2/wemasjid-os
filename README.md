# WeMasjid OS

Raspberry Pi image for WeMasjid Screens (prayer-times display). Boots to a PIN; link it from the WeMasjid dashboard under **Screens → Link a device**.

- Download: https://wemasjid.com/os/wemasjid-os.img.xz
- Raspberry Pi Imager repo: https://wemasjid.com/os/imager.json
- Docs: https://wemasjid.com/docs/screens/raspberry-pi

Supports Raspberry Pi 3B+, 4, 5 and Zero 2 W (64-bit). Images are published as releases here; source lives in the private WeMasjid platform repository.
